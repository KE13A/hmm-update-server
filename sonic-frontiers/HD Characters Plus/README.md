# HD Characters Plus
HD Characters Plus Mod for Sonic Frontiers\
This mod is a continuation of spoon Scribble's HD Characters with custom animations mods like Meoloh's and ChaosX's animation mods.

Sonic's Flow Animations are a compilation of animations that I tended to like the most. Here are some of those animations refereced:
    Forceful Animations:
    - Grind Animations
    - Quick Turn
    - Light Dash
    - Dash Ring
    - Spring Jump 

    Meoloh:
    - Idle
    - Boost Ready
    - Bump Roll

    Mitos Reanimated Sonic:
    - Rail Animations
    - Air Boost
    - Rail Jump
    - Hang

    Top Animations:
    - Jumpboard
    - Parry
    - Spring Jump
    - Homing attack Tricks

    Sonic Frontiers Revisited:
    - Running animation

    Sonics Tweaked:
    - Running boost animation
    - Crouch
    - Quickstep animation
    - Stomp animation
